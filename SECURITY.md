# Reporting an error or a security issue

Thank you for taking the time. This repository publishes research on public on-chain data. It is not a service and it holds no funds, so most reports are about a statement that may be wrong, incomplete or unfair, and those are welcome.

## How to reach us

- **Privately**, for anything that should not be public (a fix still in progress, a secret committed by mistake, a correction you would rather not discuss in the open): write to contact@realspap.com and put `onchain-postmortems` in the subject.
- **Publicly**: open a GitHub issue on this repository.

## What is in scope

- A statement, figure, date or attribution in an entry or in the Index, including the corrections table.
- A script that queries the chain and returns something different from its saved output for a historical block.
- A dollar figure that does not follow from its source files.
- Anything in the repository that identifies a person who should not be identified, or any secret committed by mistake.

## What is not in scope

- The contracts and systems of the projects named here. If you found a flaw in one of them, please report it to that team through its own channel.
- Opinions on prices, tokens or investments. This is independent research, not a security audit and not advice.

## What to include

The place concerned, the statement you dispute, and whatever supports your reading that anyone can re-read: a transaction hash, a block number, an address with the call to make, a code reference or a public document.

## What happens next

- Reports are read as time allows; replies are best effort, with no promised delay.
- When a statement is shown to be wrong, it is corrected in the entry itself and the correction is recorded in [CHANGELOG.md](CHANGELOG.md). Corrections are made in public, in the files themselves.
- When a report concerns an issue that is not yet fixed, the relevant detail is withheld from this repository until the team concerned has had the chance to fix it.
- Credit is given on request. There is no bug bounty.

This file covers the content of this repository only. The author does not act for, or speak on behalf of, any project named here.
