# Reporting an error or requesting a correction

This repository publishes reconstructions of past incidents. If you think
an entry is wrong, incomplete, or unfair to you or to a project you
represent, please say so.

## How to reach the author

- **Privately:** send a direct message on X to
  [@RealSpap](https://x.com/RealSpap). Use this channel for anything that
  should not be public, including a fix still in progress, a
  vulnerability that is not yet patched, or a correction you would rather
  not discuss in the open.
- **Publicly:** open a GitHub issue on this repository.

Please include the entry concerned (its folder name), the statement you
dispute, and whatever evidence supports your reading: a transaction hash,
a block number, a post-mortem, or a code reference.

## What happens next

- Every report is read.
- When a statement is shown to be wrong, it is corrected in the entry
  itself, and the correction is recorded in [CHANGELOG.md](CHANGELOG.md).
  Corrections are made in public; nothing is silently rewritten.
- When a report concerns an issue that is not yet fixed, the relevant
  detail is withheld from this repository until the team concerned has
  had the chance to fix it.

## Scope

This file covers the content of this repository. It does not offer a bug
bounty, and the author does not act for, or speak on behalf of, any
protocol named here.
